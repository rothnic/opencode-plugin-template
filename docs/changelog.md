## [0.1.0] - 2026-01-26

### Added
- Initial template structure with comprehensive plugin support
- Example plugin implementation with all common hooks
- Custom tools example with JSON schema validation
- Custom agents examples (code reviewer, documentation writer)
- Skills library with debugging and refactoring patterns
- Lefthook configuration for git hooks management
- lslint configuration for naming conventions and directory structure
- Version management script for bumping versions
- TypeScript support with Bun runtime
- Comprehensive README with quick start guide
- BEST_PRACTICES.md with detailed guidelines
- CONTRIBUTING.md with contribution guidelines
- Example implementations for:
  - Session lifecycle hooks
  - Tool execution hooks
  - Message hooks
  - File operation hooks
  - Permission hooks
  - Git hooks
- Project structure with `.opencode/` directory organization
- Package configuration for npm publishing
- OpenCode configuration file (opencode.json)

### Documentation
- Complete README with usage instructions
- Best practices guide
- Contributing guidelines
- Example code with comments
- Type definitions for better IDE support
